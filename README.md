# widdlab/homebrew-tap

Homebrew tap for [widdlab](https://github.com/widdlab) tools.

## Install

```sh
brew tap widdlab/tap
brew install krapow
```

## Formulas

- [`krapow`](https://github.com/widdlab/krapow) — Run GitHub Actions self-hosted runners as Incus or Tart VMs

Formulas in this tap are auto-published by goreleaser when their upstream
project tags a release.
